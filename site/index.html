字符串值

宿主对象与 Proxy

可指定宿主对象和属性名。先赋值，再读回子容器继续写入，兼容 Vue 深层响应式代理。

parse(chunks, host, "data")
04

异步字符串块

每个输入项可以是单字符或长字符串。块边界可位于字符串、转义或数字内部，解析状态跨块保留。

yield '{"ti'→yield 'tle":'
✓
输入结束后返回完整结果

parse 等待来源结束，通过 EOF 语法校验后返回根值。非法 JSON 或未完成输入会以 SyntaxError 拒绝。
