Vue 流式 JSON 示例

把正在构造的对象显示到页面

模板直接读取对象，字符串和数组项逐步显示。
computed 随价格写入重新计算金额。

核心代码完整代码 · Gist ↗

JavaScript

import { computed, reactive } from "vue";
import { parse } from "gradual-json";

const host = reactive({});
const items = computed(() => host.data?.items ?? []);
const total = computed(() =>
  items.value.reduce((sum, item) =>
    sum + (item.price ?? 0), 0)
);

async function start() {
  await parse(chunks(), host, "data");
}

Vue 模板

<h3>{{ host.data?.title }}</h3>
<p>{{ host.data?.author?.name }}</p>
<article v-for="(item, i) in items" :key="i">
  <h4>{{ item.label }}</h4>
  <span v-if="item.price !== undefined">
    ¥ {{ item.price }}
  </span>
</article>
<p v-if="items.some(item => item.price !== undefined)">
  已读金额：¥ {{ total.toFixed(2) }}
</p>

chunks() 产出异步字符串块。模板直接读取宿主对象，金额由 Vue 自动重算。
