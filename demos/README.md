# 流式处理演示

在项目根目录运行以下命令。使用项目现有的 Vue、TypeScript 与 Node 内置模块，无需额外依赖；终端演示通过 Node 直接导入 TypeScript 源码（当前项目使用 Node 24）。

`parse` 接受异步迭代器产出的字符串块，块长度可以任意，包括空块和单字符块。解析器在块内按索引逐个读取 UTF-16 单元，交给状态函数；不需要选择输入模式。

## 延时异步字符流

```sh
npm run demo:chars
```

异步生成器逐字符送入 `parse`，每个片段结束后打印宿主对象。留意 `{` / `[` 到达时空容器就已挂载；字符串值的开引号先写入空串，尚未闭合的标题和数组项名称也会随字符逐步出现。简单转义和 `\uXXXX` 在完整解码后更新一次。对象键仍在闭引号后才确定；数字、布尔和 `null` 完整前不会写入。来源结束后，`await parse(...)` 才返回根值，返回引用与 `host.data` 相同。

## Node Readable 与 UTF-8 分块

```sh
npm run demo:node
```

真实 `Readable` 定时收到 `Buffer` 块。“流”的 UTF-8 字节拆为 `1 + 2`，“🌊”拆为 `2 + 2`。`setEncoding('utf8')` 保留跨块的 UTF-8 字节；演示随后用 `for await` 取解码字符串块，直接传给 `parse`，逐块打印正在构造的数据。原始块和解码块不一定一一对应。实际使用时，也可以直接调用 `parse(readable, host, 'data')`，其中 `readable` 已设置字符串编码。

## Vue 页面与真实 HTTP 响应

```sh
npm run demo:vue
```

打开 <http://127.0.0.1:4173>，选择本地延时字符流或 HTTP 分块响应，再点击“开始演示”。页面并排展示已经收到的输入、正在构造的对象，以及逐步出现的作者、数组项、价格和标签。选择慢速更容易看到空容器先出现、标题和名称逐字符增长、价格等完整后再写入的过程。

页面直接使用 `parse(chunks, reactive宿主, 'data')`，不提前解析完整 JSON。HTTP 模式读取真实 `/stream` 响应：服务定时发送字节块，并刻意在中文和 emoji 中间断开；浏览器使用 `TextDecoderStream` 保留 UTF-8 边界，解码后的字符串块直接交给解析器。本地延时演示仍每次产出一个 UTF-16 单元，用于观察字符到达时的细节。

“停止”会取消当前来源并保留已构造的部分，不显示解析完成。重新开始会清空展示；前一轮的迟到数据不会写入新一轮。只有收到来源 EOF 且状态校验通过，页面才标记完成。

服务仅监听 `127.0.0.1`，页面、Vue 和解析器均由本地固定路由提供。解析器在服务启动时用现有 TypeScript 转译到内存，不生成构建文件。可使用环境变量修改端口：

```sh
PORT=4180 npm run demo:vue
```

按 `Ctrl+C` 关闭服务。三个演示的样例都包含中文、emoji、嵌套对象与数组，以及字符串、数字、布尔值和 `null`。
